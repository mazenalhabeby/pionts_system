How Pionts Works

Pionts is a plug-and-play loyalty platform. Your shop communicates with Pionts via a simple API — 4 backend calls and 1 frontend snippet.

Step 1

Embed Widget

Add the floating loyalty widget to your storefront. Customers see their points, redeem rewards, and share referral links.

Step 2

Send Orders

After payment, tell Pionts about the order. Points are awarded automatically based on your earn rules.

Step 3

Validate Codes

When customers enter a loyalty discount code at checkout, validate it with Pionts and apply the discount.

Custom API Integration

For any platform with a backend — Node.js, Python, PHP, Go, etc. The Node.js SDK handles everything, or use the REST API directly.

1

Install the SDK

npm install @pionts/sdk
2

Initialize the Client

import { PiontsClient } from '@pionts/sdk';

const pionts = new PiontsClient({
  apiUrl: 'https://your-pionts-server.com',
  secretKey: process.env.PIONTS_SECRET_KEY, // sk_live_...
});
3

Validate Discount Codes at Checkout

When a customer enters a code, check with Pionts:

const result = await pionts.checkout.validate(code);

if (result.valid) {
  // Apply discount of result.discountAmount to the order
  order.discount = result.discountAmount;
}
4

Award Points After Payment

// After successful payment:
await pionts.orders.paid({
  orderId: order.id,
  email: customer.email,
  customerName: customer.name,
  orderTotal: order.total,
  currency: 'EUR',
});

// If loyalty code was used, mark it:
if (order.loyaltyCode) {
  await pionts.checkout.markUsed(order.loyaltyCode);
}
5

Handle Refunds

await pionts.orders.refunded(order.id, refundAmount);
6

Add the Widget

Server-side — generate HMAC for the logged-in customer:

const init = await pionts.widget.init(user.email, user.name);
// Returns: { projectKey, hmac, apiBase, email, name }

Frontend — load the widget:

<script src="https://your-pionts-server.com/sdk/loyalty.js" async></script>
<script src="https://your-pionts-server.com/widget/pionts-widget.umd.js" async></script>

<script>
window.__PIONTS_CONFIG__ = {
  projectKey: '{{ projectKey }}',
  customer: { email: '{{ email }}', name: '{{ name }}', hmac: '{{ hmac }}' },
  mode: 'floating',
  apiBase: 'https://your-pionts-server.com',
  locale: 'en',
  currency: { symbol: '€', position: 'prefix', decimals: 2 },
  containerEl: document.getElementById('pionts-root'),
};
</script>
<div id="pionts-root"></div>
That's it! 4 backend hooks + 1 frontend snippet. Your shop now has a fully integrated loyalty program.

Shopify Integration

Zero code required. Install the app and everything is automatic.

1

Install the App

Go to the Shopify App Store, search for "Pionts", and click Install. Authorize the app when prompted.

The app automatically:

  • Creates your Pionts project
  • Generates API keys
  • Registers webhooks for orders and refunds
  • Injects the loyalty widget into your theme
2

Configure Your Program

In the Pionts admin dashboard:

  • Earn Actions — points per purchase, signup bonus, birthday bonus, social follow rewards
  • Redemption Tiers — e.g., 50 pts = €5 off, 100 pts = €10 off
  • Referral Rewards — points per referral level
  • Widget — customize colors to match your brand
3

Done

Everything is automatic from here:

EventWhat Happens
Customer purchasesPoints awarded via Shopify webhook
Customer redeems in widgetDiscount code created in Shopify
Customer uses code at checkoutShopify applies the discount
Order refundedPoints reversed via webhook
Optional: Add a Customer Account Rewards Page using the Shopify UI Extension for a dedicated loyalty page in customer accounts.

WooCommerce Integration

WordPress plugin + webhook setup. Works with any WooCommerce store.

1

Create a Pionts Project

Sign up at your Pionts admin dashboard, create a project, and choose WooCommerce as the platform. Copy your API keys.

2

Add Widget to Your Theme

Add this to your theme's footer.php (before </body>):

<?php if (is_user_logged_in()):
  $user = wp_get_current_user();
  $email = $user->user_email;
  $name = $user->display_name;
  $hmac = hash_hmac('sha256', $email, 'YOUR_HMAC_SECRET');
?>
<div id="pionts-root"></div>
<script src="https://your-pionts-server.com/sdk/loyalty.js" async></script>
<script src="https://your-pionts-server.com/widget/pionts-widget.umd.js" async></script>
<script>
window.__PIONTS_CONFIG__ = {
  projectKey: 'YOUR_PROJECT_KEY',
  customer: { email: '<?= esc_js($email) ?>', name: '<?= esc_js($name) ?>', hmac: '<?= $hmac ?>' },
  mode: 'floating',
  apiBase: 'https://your-pionts-server.com',
  containerEl: document.getElementById('pionts-root'),
};
</script>
<?php endif; ?>
3

Set Up WooCommerce Webhooks

Go to WooCommerce → Settings → Advanced → Webhooks. Create 2 webhooks:

NameTopicDelivery URL
Pionts: Order PaidOrder completedhttps://your-pionts-server.com/api/v1/webhooks/order
Pionts: RefundOrder refundedhttps://your-pionts-server.com/api/v1/webhooks/refund

Set the Secret to your Pionts secret key (sk_live_...).

4

Optional: Validate Loyalty Codes at Checkout

Add this to your theme's functions.php to validate Pionts loyalty codes at WooCommerce checkout:

add_action('woocommerce_coupon_loaded', function($coupon) {
  $code = $coupon->get_code();
  $response = wp_remote_post('https://your-pionts-server.com/api/v2/checkout/validate', [
    'headers' => [
      'Content-Type' => 'application/json',
      'X-Api-Key' => 'YOUR_SECRET_KEY',
    ],
    'body' => json_encode(['code' => $code]),
  ]);
  $body = json_decode(wp_remote_retrieve_body($response), true);
  if ($body && $body['valid']) {
    $coupon->set_amount($body['discountAmount']);
    $coupon->set_discount_type('fixed_cart');
  }
});
5

Configure & Test

In the Pionts admin, configure earn actions, redemption tiers, and referral levels. Place a test order to verify points are awarded.

API Reference

Base URL: https://your-pionts-server.com/api/v2
Auth: X-Api-Key: sk_live_... header on all requests.

Checkout

MethodEndpointDescription
POST/checkout/validateValidate a loyalty discount code
POST/checkout/mark-usedMark code as used after payment

Orders

MethodEndpointDescription
POST/orders/paidNotify order paid — awards loyalty points
POST/orders/refundedNotify refund — reverses points

Customers

MethodEndpointDescription
GET/customers/:emailGet balance, history, profile
POST/customers/:email/redeemRedeem points for discount code
DELETE/customers/:email/redemptions/:idCancel redemption

Config & Widget

MethodEndpointDescription
GET/configGet earn actions, tiers, settings
POST/widget/initGenerate HMAC for widget auth

Webhooks

MethodEndpointDescription
POST/webhooksRegister webhook endpoint
GET/webhooksList registered webhooks
DELETE/webhooks/:idRemove webhook
GET/webhooks/:id/logsView delivery history
POST/webhooks/:id/testSend test event

Request / Response Examples

POST /checkout/validate

// Response (invalid)
{ "valid": false }

  "orderId": "ORD-001",
  "email": "customer@example.com",

  "orderTotal": 99.99,

// Response

Webhook Events

EventTriggered When
redemption.createdCustomer redeems points
redemption.cancelledCustomer cancels redemption
redemption.usedCode marked as used
order.points_awardedPoints awarded for purchase
customer.createdNew customer registered

Each delivery includes:

  • X-Pionts-Signature: sha256=<hmac> — verify with the SDK
  • X-Pionts-Event-Id: <uuid> — idempotency key
  • X-Pionts-Event-Type: <event> — event name
