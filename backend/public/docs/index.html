Add loyalty points, referrals, and rewards to any e-commerce platform in minutes.

Pionts connects to your shop via a simple API. Your backend makes 4 calls, your frontend loads a widget — customers start earning and redeeming points immediately.

Architecture
┌──────────────┐         ┌──────────────┐         ┌──────────────┐
│   Customer   │────────▶│  Your Shop   │────────▶│    Pionts    │

const pionts = new PiontsClient({

2. Checkout — Validate Discount Code

When a customer enters a discount code at checkout, check if it's a Pionts loyalty code:

TypeScript
async function validateDiscount(code: string, subtotal: number) {
  // Check your own discount codes first
  const local = await db.discounts.findByCode(code);
  if (local) return local;

  // Check Pionts for loyalty codes
  const result = await pionts.checkout.validate(code);
  if (result.valid) {
    return {
      type: 'loyalty',
      amount: Math.min(result.discountAmount, subtotal),
    };
  }

  return null; // Invalid code
}
⚠️
Important: Always validate loyalty codes with Pionts at checkout time — never trust a locally cached code. Customers can refund redemptions, which invalidates the code in Pionts.

3. Payment Success — Award Points & Mark Used

TypeScript
async function onPaymentSuccess(order: Order) {
  // Award loyalty points for the purchase
  await pionts.orders.paid({
    orderId: order.id,
    email: order.customerEmail,
    customerName: order.customerName,
    orderTotal: order.total,
    currency: order.currency,
    referralCode: order.referralCode, // optional
  });

  // If customer used a loyalty discount code, mark it as used
  if (order.discountType === 'loyalty') {
    await pionts.checkout.markUsed(order.discountCode);
  }
}

4. Refunds — Reverse Points

TypeScript
async function onRefund(orderId: string, amount: number) {
  await pionts.orders.refunded(orderId, amount);
}

PHP Integration

For Laravel, Symfony, or raw PHP backends. Uses cURL directly until the PHP SDK is available.

Helper Function

PHP
function pionts_api(string $method, string $endpoint, array $data = null): array {
    $url = getenv('PIONTS_API_URL') . '/api/v2' . $endpoint;

    $ch = curl_init($url);
    curl_setopt_array($ch, [
        CURLOPT_CUSTOMREQUEST  => $method,
        CURLOPT_HTTPHEADER     => [
            'Content-Type: application/json',
            'X-Api-Key: ' . getenv('PIONTS_SECRET_KEY'),
        ],
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_TIMEOUT        => 10,
    ]);

    if ($data) {
        curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
    }

    $response = curl_exec($ch);
    curl_close($ch);

    return json_decode($response, true) ?: [];
}

Python Integration

For Django, Flask, FastAPI, or any Python backend.

Helper Class

Python
import os, requests, hmac, hashlib

class PiontsClient:
    def __init__(self):
        self.base = os.environ['PIONTS_API_URL'] + '/api/v2'
        self.headers = {
            'Content-Type': 'application/json',
            'X-Api-Key': os.environ['PIONTS_SECRET_KEY'],
        }

    def validate(self, code: str) -> dict:
        r = requests.post(f'{self.base}/checkout/validate',
                          json={'code': code}, headers=self.headers, timeout=10)
        return r.json()

    def mark_used(self, code: str):
        requests.post(f'{self.base}/checkout/mark-used',
                      json={'code': code}, headers=self.headers, timeout=10)

    def order_paid(self, order_id: str, email: str, total: float, currency='EUR'):
        requests.post(f'{self.base}/orders/paid', json={
            'orderId': order_id, 'email': email,
            'orderTotal': total, 'currency': currency,
        }, headers=self.headers, timeout=10)

    def order_refunded(self, order_id: str, amount: float):
        requests.post(f'{self.base}/orders/refunded', json={
            'orderId': order_id, 'refundAmount': amount,
        }, headers=self.headers, timeout=10)

    @staticmethod
    def widget_hmac(email: str) -> str:
        secret = os.environ['PIONTS_HMAC_SECRET']
        return hmac.new(secret.encode(), email.encode(), hashlib.sha256).hexdigest()

pionts = PiontsClient()

from .pionts import pionts

Delivery Headers

Each webhook delivery includes these headers:

HeaderDescription
X-Pionts-Signaturesha256=<hmac> — HMAC-SHA256 of the body using your endpoint secret
X-Pionts-Event-IdUnique event ID for idempotency
X-Pionts-Event-TypeEvent name (e.g. redemption.created)

Verify Signatures

TypeScript
import { PiontsWebhook } from '@pionts/sdk';

app.post('/webhooks/pionts', (req, res) => {
  const sig = req.headers['x-pionts-signature'];
  const valid = PiontsWebhook.verify(req.rawBody, sig, endpointSecret);

  if (!valid) return res.status(401).send('Invalid signature');

  const { event, data } = req.body;
  // Handle event...
});

Retry Policy

Failed deliveries are retried 3 times with exponential backoff: 10s, 60s, 300s. After 3 failures, the delivery is marked as permanently failed. View logs in the dashboard or via the /webhooks/:id/logs endpoint.

HMAC Authentication

The widget uses HMAC-SHA256 to verify customer identity. The HMAC is computed server-side using your HMAC secret + customer email. This prevents customers from impersonating others.

🔒
Never expose your HMAC secret or secret API key on the frontend. Generate the HMAC on your server and pass it to the frontend.

Webhook Signatures

All webhook deliveries are signed with HMAC-SHA256. Verify the X-Pionts-Signature header before processing:

TypeScript
import { PiontsWebhook } from '@pionts/sdk';
const isValid = PiontsWebhook.verify(rawBody, signature, secret);

Checkout Security

  • Always validate loyalty codes with Pionts at checkout — never trust a locally cached code
  • Call mark-used after payment — prevents customers from refunding points and still using the discount
  • Idempotent order notifications — duplicate order-paid calls are safely ignored

SDK Error Handling

TypeScript
import { PiontsError, PiontsTimeoutError } from '@pionts/sdk';

try {
  await pionts.checkout.validate(code);
} catch (err) {
  if (err instanceof PiontsTimeoutError) {
    // Request timed out — Pionts may be slow
    // Decide: reject code or allow gracefully
  } else if (err instanceof PiontsError) {
    console.log(`API error ${err.statusCode}: ${err.message}`);
  }
}

Retry Behavior

The SDK automatically retries once on 5xx errors and network failures (with 1s delay). Timeouts are not retried. Configure the timeout via new PiontsClient({ timeout: 15000 }).
